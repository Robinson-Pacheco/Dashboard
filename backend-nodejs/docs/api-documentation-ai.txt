# Documentación de API: Business Intelligence API for University Admission Data

## Información General
- **Versión**: 1.0.0
- **Descripción**: API for processing and analyzing university admission test data
- **Servidor**: http://localhost:3000

## Endpoints

### Business Intelligence

**GET `/api/bi/statistics`**
- **Resumen**: Get admission statistics by period and year
- **Descripción**: Returns statistical data about admissions for a specific period and year
- **Autenticación**: ✅ Requerida
- **Parámetros**:
  - `period` (query): Academic period (e.g., 20252)
  - `year` (query): Academic year (e.g., 2025)
- **Éxito**: Successful operation

**GET `/api/bi/trends`**
- **Resumen**: Get admission trends over time
- **Descripción**: Returns admission data trends across multiple periods
- **Autenticación**: ✅ Requerida
- **Éxito**: Successful operation

**GET `/api/bi/demographics`**
- **Resumen**: Get demographic breakdown of applicants
- **Descripción**: Returns demographic data about applicants including gender, residence, and education type
- **Autenticación**: ✅ Requerida
- **Éxito**: Successful operation

**GET `/api/bi/performance`**
- **Resumen**: Get performance analysis by component
- **Descripción**: Returns performance data broken down by test components
- **Autenticación**: ✅ Requerida
- **Éxito**: Successful operation

**GET `/api/bi/disability`**
- **Resumen**: Get disability statistics
- **Descripción**: Returns statistics about applicants with disabilities
- **Autenticación**: ✅ Requerida
- **Éxito**: Successful operation

**GET `/api/bi/periods-years`**
- **Resumen**: Get available periods and years
- **Descripción**: Returns a list of available periods and years from admission data
- **Autenticación**: ✅ Requerida
- **Éxito**: Successful operation

**GET `/api/bi/dashboard`**
- **Resumen**: Get comprehensive dashboard data
- **Descripción**: Returns all necessary data for the business intelligence dashboard
- **Autenticación**: ✅ Requerida
- **Parámetros**:
  - `period` (query): Academic period (e.g., 20252)
  - `year` (query): Academic year (e.g., 2025)
- **Éxito**: Successful operation

### Admission Data

**POST `/api/admission/upload`**
- **Resumen**: Upload and process admission data from Excel file
- **Autenticación**: ✅ Requerida
- **Éxito**: File processed successfully

**GET `/api/admission/`**
- **Resumen**: Get admission data with optional filters
- **Autenticación**: ✅ Requerida
- **Parámetros**:
  - `period` (query): Filter by academic period (e.g., 2025-2)
  - `year` (query): Filter by academic year
  - `page` (query): Page number for pagination
  - `limit` (query): Number of records per page
- **Éxito**: Admission data retrieved successfully

**GET `/api/admission/stats`**
- **Resumen**: Get admission statistics
- **Autenticación**: ✅ Requerida
- **Parámetros**:
  - `period` (query): Filter by academic period (e.g., 2025-2)
  - `year` (query): Filter by academic year
- **Éxito**: Admission statistics retrieved successfully

### Authentication

**POST `/api/auth/register`**
- **Resumen**: Register a new user
- **Éxito**: User registered successfully

**POST `/api/auth/login`**
- **Resumen**: Authenticate user and get JWT token
- **Éxito**: Login successful

**GET `/api/auth/me`**
- **Resumen**: Get current user information
- **Autenticación**: ✅ Requerida
- **Éxito**: User information retrieved successfully

**GET `/api/auth/users`**
- **Resumen**: Get all users (Admin only)
- **Autenticación**: ✅ Requerida
- **Éxito**: Users retrieved successfully

**DELETE `/api/auth/users/{id}`**
- **Resumen**: Delete a user (Admin only)
- **Autenticación**: ✅ Requerida
- **Parámetros**:
  - `id` (path): User ID to delete (requerido)
- **Éxito**: User deleted successfully
